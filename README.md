# Repository About Generative Geometric Deep Learning

This is a repo to document my own progress and experimentation with implementing 
different model architectures, approaches, etc. relevant for my research.  
  
The models and other things implemented here are for educational purposes mostly. 
In other words
- Most of the code will be unoptimized, although I attempt to avoid or overcome fullz naive implementations of different mathematical transformations or architectures.
- The code is based on a personal understanding and interpretation of the underlying papers/research, aided by ChatBots. As such, it is likely there might be some mistakes here and there as I do not have a formal math background.
  
## Content

What I will implement and when will be based on personal preference and necessity, but so far includes and might include in the future:
- Basic generative modeling, with heavy emphasis on probability flow-based models, i.e. *[in progress]*
    - Normalizing flows
    - (Denoising) Diffusion / score-based generative models (SBGMs)
    - Flow matching
- Graph-geometric deep learning, i.e. graph neural networks (GNNs) *[planned]*
    - With that, graph-generative methods, where I will focus on small molecules for experimenting
- Other geometric DL approaches, i.e. topological deep learning and differential geometry appraoches *[so far, only a wish]*
- Hybrid neural-mechanistic modeling, i.e. neural differential equations, neural operators, etc. *[ideas but not a priority]*
- Symbolic regression / grammar-based approaches, using deep learning *[so far, only a wish]*
- Neural architecture search *[right now, only very unoptimized implementations using metaheuristics]*
  
I will update the repository and my progress as I go along.
